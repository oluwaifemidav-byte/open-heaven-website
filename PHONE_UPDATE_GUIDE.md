# Phone-friendly update guide

This website is designed so you can make common updates without an admin page.

## Edit the main details from your phone
Open the file:

- church-config.js

Change these values as needed:

- churchName
- churchEmail
- churchAddress
- whatsappNumber
- givingAccount.bank
- givingAccount.accountName
- givingAccount.accountNumber
- givingAccount.accountType
- socialLinks.youtube
- socialLinks.instagram
- socialLinks.facebook
- socialLinks.whatsapp

## How to update it
1. Open the repository in GitHub on your phone.
2. Tap the file named church-config.js.
3. Edit the values.
4. Save with a commit.

If the site is published through GitHub Pages or another hosting service, the new values will appear live after deployment.

## Best practice
Keep all permanent church information here instead of writing it into separate HTML pages. This keeps the site simple and easy to manage without a backend.
