RCCG OPEN HEAVENS CHURCH — WEBSITE STARTER
==========================================

This is a responsive five-page static website:
1. index.html      — Home
2. about.html      — About Us
3. ministries.html — Ministries
4. events.html     — Services & Events
5. contact.html    — Contact / Plan a Visit

Also included:
- styles.css — site-wide styling and responsive mobile layout
- script.js  — mobile menu, current year, and contact form demo

BEFORE PUBLISHING
-----------------
1. Replace [Add your full church address], [Add official church email], and
   [Add official phone number] in contact.html.
2. Open script.js and replace YOUR-CHURCH-EMAIL@example.com with the real
   official church email. The form then prepares an email in the visitor's
   email app; it does not send messages through a server.
3. Confirm the service schedule, church name, and all wording with church
   leadership before publishing.
4. The photos are loaded from Unsplash URLs and Google Fonts from Google Fonts,
   so an internet connection is needed to display those assets.
5. This is a static site. It can be hosted on Netlify, GitHub Pages, or any
   static web host. To deploy to Netlify, drag the extracted folder into the
   Netlify deploy area, or connect it to a Git repository.

DESIGN
------
Warm cream, deep green, and gold palette; serif headings; responsive layouts;
mobile navigation; service schedule; ministry cards; contact form demo.

The site intentionally uses placeholders for contact details rather than
inventing the church's address or phone number.
